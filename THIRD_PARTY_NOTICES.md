# Third-party software

`Install.exe` includes the following. Each stays under its own license.

| Component | Use | License |
|---|---|---|
| [Node.js](https://nodejs.org) | Runs the local server | MIT and others, see nodejs.org |
| [ViGEmBus](https://github.com/nefarius/ViGEmBus) | Virtual controller driver (official signed installer, unmodified) | BSD-3-Clause |
| [Nefarius.ViGEm.Client](https://github.com/nefarius/ViGEm.NET) | Talks to the driver | MIT |
| [ws](https://github.com/websockets/ws) | WebSocket server | MIT |
| [node-datachannel](https://github.com/murat-dogan/node-datachannel) | WebRTC | MPL-2.0 |
| [koffi](https://koffi.dev) | Calls Windows APIs for mouse and keyboard input | MIT |
| [qrcode](https://github.com/soldair/node-qrcode) | QR codes | MIT |
| [selfsigned](https://github.com/jfromaniello/selfsigned) | Local certificates | MIT |

The full license text of each npm package is in its folder under `testbench/node_modules` after `npm install`. Fonts in `testbench/public/fonts` (DotGothic16, Sora, Space Mono) are under the SIL Open Font License.
